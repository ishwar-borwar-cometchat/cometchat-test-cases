- Context Menu / Logout / New Chat (create conversation, logout flow)
- Create Group (public/private/password types, validation)

- User Details Side Panel (block/unblock, delete chat, confirmations)
- Group Details Side Panel (members, banned, add members, leave, delete & exit, transfer ownership)
- Threaded Messages (thread view, composer, blocked user, search highlighting)
- Message Search in Chat (in-conversation search, result navigation)
- Conversations Search (global search, message/conversation results)
- Blocked User Flow (composer hidden, unblock link, real-time updates)
- Call Log Details (participants, recordings, history, status icons)
- Transfer Ownership (radio selection, execute transfer, cancel)
- Banned Members (list, unban, real-time updates, empty state)
- Add Members (multi-select, count display, execute add)
- AI Assistant Chat (agentic user detection)
- Toast Notifications (all group/user action toasts)
- Alert Popup (kicked/banned from group)
- Message Delivery (auto mark delivered)
- Fresh Chat (first message detection, conversion)
